# 百度地图小人移动动画

这是一个使用百度地图 API 实现的小人移动动画演示项目。

## 功能特点

- 使用百度地图 API 显示地图
- 实现路线规划功能
- 自定义小人图标
- 平滑的移动动画效果

## 安装和运行

1. 克隆项目：
```bash
git clone [项目地址]
```

2. 安装依赖：
```bash
npm install
```

3. 启动服务器：
```bash
npm start
```

4. 在浏览器中访问：
```
http://localhost:3000
```

## 技术栈

- HTML5
- CSS3
- JavaScript
- 百度地图 API

## 注意事项

- 需要有效的百度地图 API Key
- 确保网络连接正常
- 建议使用现代浏览器访问
